# IMightBeInDebt's Networked MonoSandbox
A mod for Gorilla Tag that adds Garry's mod things into Gorilla Tag (but networked).

<img src="https://raw.githubusercontent.com/IMightBeInDebt/NetworkedMonoSandbox/main/gifs/gif2.gif">

---

# Controls
- Open Settings: Z **(PC)**
- Open Menu: X **(VR)**
- Ragdoll: Y **(VR)**
- Place: A **(VR)**
- Activate: B **(VR)**
- Use/Shoot: Right Trigger **(VR)**

  <img src="https://raw.githubusercontent.com/IMightBeInDebt/NetworkedMonoSandbox/main/gifs/gif1.gif">

---

# Installation

- Download the mod from [here](https://github.com/IMightBeInDebt/NetworkedMonoSandbox/releases/latest)
- Drag the file `MonoSandbox.dll` to your plugins folder
- Start Gorilla Tag if needed

---

# Dependencies

- Utilla 1.7.0 or later
- BepInEx 5.4 or later
- Gorilla Tag
